# Windows 服务器部署与持续运行指南

本指南将帮助您在 Windows 环境下部署 Feishu 展示与同步系统，并确保其在外网可访问的情况下稳定运行。

---

## 1. 基础环境准备

在开始之前，请确保您的 Windows 服务器已安装以下软件：
- **Node.js (v18.x 或更高版本)**：[下载地址](https://nodejs.org/)
- **PostgreSQL 数据库**：请确保数据库已运行且对应的 `.env` 配置正确。

> [!IMPORTANT]
> **开放端口**：
> 请在您的云服务器控制台（阿里云/腾讯云等）的“安全组”或“防火墙”设置中，放行以下入站规则：
> - TCP 端口 **3000** (同步看板)
> - TCP 端口 **4000** (外部展示)
> - (可选) 如果之后想用标准网页访问，放行 **80** 和 **443**。

## 2. 快速启动项目

我为您创建了一个一键启动脚本 `start_apps.bat`。

**操作步骤**：
1. 打开 `d:\aaa\Exhibit\LocalSync` 文件夹。

   - 补齐项目依赖包 (`npm install`)。
   - 启动两个服务并保存在后台运行。

---

## 3. 实现“开机自启”与“持久化运行”

仅仅启动是不够的，为了防止服务器重启后服务中断，我们需要将 PM2 设为 Windows 服务。

### 方案：使用 Windows 计划任务 (推荐)

1. 按 `Win + R`，输入 `taskschd.msc` 打开**任务计划程序**。
2. 点击右侧“**创建基本任务**”：
   - 名称：`PM2 Resurrect`
   - 触发器：选择“**计算机启动时**”。
   - 操作：选择“**启动程序**”。
   - 程序或脚本：填写 `pm2` 的完整路径（通常在 `C:\Users\您的用户名\AppData\Roaming\npm\pm2.cmd`）。
   - 添加参数：`resurrect`
3. 在“完成”前，勾选“打开此任务的属性对话框”。
4. 在属性中，选择“**不管用户是否登录都要运行**”，并勾选“**使用最高权限运行**”。

---

## 4. 常用管理指令 (CMD/PowerShell)

在之后维护过程中，您可以打开终端输入以下指令：

- **查看所有服务状态**：
  ```bash
  pm2 status
  ```
- **查看实时日志**：
  ```bash
  pm2 logs
  ```
- **重启所有服务**：
  ```bash
  pm2 restart all
  ```
- **停止某个服务**：
  ```bash
  pm2 stop FeishuSyncLocal
  ```

## 5. 外网访问

### 直接 IP 访问 (当前状态)
确保端口已开放后，您可以使用以下地址从外网访问：
- **同步看板**：`http://您的公网IP:3000`
- **外部展示端**：`http://您的公网IP:4000`

### 进阶：配置 Nginx (可选)
如果您希望直接通过 `http://您的公网IP` 访问（省略端口号），可以在服务器上安装 Nginx Windows 版，并将请求转发到 3000 或 4000 端口。
